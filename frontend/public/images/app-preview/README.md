# Imagem do Preview do App

## Como adicionar a imagem

1. Coloque a imagem da tela do celular (a que você mostrou) neste diretório
2. Nomeie o arquivo como: `treinos-screen.png` (ou `.jpg`, `.webp`)
3. A imagem será exibida automaticamente na landing page

## Formato recomendado

- **Formato**: PNG, JPG ou WEBP
- **Dimensões**: Idealmente 400x800px ou proporção similar (retrato)
- **Tamanho**: Otimize para web (máximo 500KB recomendado)

A imagem deve mostrar a tela do app "Treinos" com a interface completa que você mostrou.
